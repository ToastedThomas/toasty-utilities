What Is a Unix Timestamp?

A Unix timestamp is the number of seconds that have passed since January 1, 1970, at 00:00:00 UTC. This starting point is known as the Unix epoch.

Unix timestamps provide a simple way to represent a specific moment in time as a number. Instead of storing a date such as January 1, 2026, 12:00:00 AM, software can store a single numeric value representing that moment.

The Unix Epoch

The Unix epoch is the reference point from which Unix timestamps are calculated. A timestamp of 0 represents the beginning of the Unix epoch, while positive timestamps represent moments after it. Dates before the epoch can be represented using negative timestamps.

Timestamps and Timezones

A Unix timestamp represents a specific moment in time rather than a particular timezone. The same timestamp can therefore be displayed as different clock times depending on the timezone being used.

For example, a timestamp representing midnight UTC will appear as a different local time for someone in another timezone. The timestamp itself does not change, only the way that moment is displayed changes.

Common Uses for Unix Timestamps

Unix timestamps are useful whenever software needs to record or compare exact points in time. They are commonly found in web development, programming, databases, APIs, and system logs.
